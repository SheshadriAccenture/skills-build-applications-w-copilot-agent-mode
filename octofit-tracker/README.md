# OctoFit Tracker (scaffold)

This folder contains the scaffold for the OctoFit Tracker application.

Structure

octofit-tracker/
├── backend/
│   ├── venv/ (virtual environment - created by the command below)
│   ├── requirements.txt
└── frontend/

Setup notes

- Create the Python virtual environment (run from the repository root):

```bash
python3 -m venv octofit-tracker/backend/venv
source octofit-tracker/backend/venv/bin/activate
pip install -r octofit-tracker/backend/requirements.txt
```

Follow the project instructions in .github/instructions for further setup.
